# Word Roots

Learn the Latin and Greek roots of English words.

- **[app/](app/)** — Root Quest, a mobile-first, offline-capable web app. See [app/README.md](app/README.md) to run it.
- **[book/](book/)** — *The Fossil Record of English*, a motivating companion to the app: source chapters, compiled Markdown, and EPUB. Run its rebuild commands from `book/`.
